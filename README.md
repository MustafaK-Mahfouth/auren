# AUREN

A responsive landing page for a luxury car brand concept, built with HTML, Sass and a little vanilla JavaScript.

## Structure
- `index.html` - the page
- `sass/` - Sass source (compile to `css/style.css`)
- `css/` - compiled stylesheet and icon font
- `js/navigation.js` - navigation behaviour
- `img/` - images and video

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.
